# E-commerce Data Analysis with Python and SQL
# 🌟 Overview
This project presents a comprehensive analysis of an e-commerce dataset, leveraging SQL for powerful data wrangling and aggregation, and Python (primarily using Pandas and Matplotlib/Seaborn) for advanced analytics, visualization, and reporting. The goal is to extract meaningful business insights, ranging from basic operational metrics to complex customer behavior and sales forecasting.

# 🚀 Key Features
Database Integration: Utilizes a SQL database (e.g., SQLite, PostgreSQL, MySQL) to efficiently store and query a large e-commerce dataset.

Structured Analysis: Addresses a set of carefully designed queries across Basic, Intermediate, and Advanced categories to derive granular insights.

Python Data Pipeline: Uses Python and the Pandas library to connect to the database, retrieve data, and perform complex calculations (e.g., moving averages, retention rates).

Data Visualization: Generates informative charts and graphs using Matplotlib/Seaborn to visualize trends in sales, customer retention, and product performance.

Reusable Code: Provides clean, well-commented SQL scripts and Python notebooks that can be adapted for similar datasets.

🔍 Analytical Queries
The project is structured around solving the following three tiers of queries (details are in the [PLACEHOLDER: e.g., queries/analytical_queries.sql] file and Python notebooks):

#Basic Queries
List all unique cities where customers are located.

Count the number of orders placed in 2017.

Find the total sales per category.

Calculate the percentage of orders that were paid in installments.

Count the number of customers from each state.

#Intermediate Queries
Calculate the number of orders per month in 2018.

Find the average number of products per order, grouped by customer city.

Calculate the percentage of total revenue contributed by each product category.

Identify the correlation between product price and the number of times a product has been purchased.

Calculate the total revenue generated by each seller, and rank them by revenue.

# Advanced Queries
Calculate the moving average of order values for each customer over their order history.

Calculate the cumulative sales per month for each year.

Calculate the year-over-year growth rate of total sales.

Calculate the retention rate of customers (purchase within 6 months of first purchase).

Identify the top 3 customers who spent the most money in each year.
